# Chi-Spark AI

Marketing website for **Chi-Spark AI**, a nonprofit AI technology incubator (in formation)
equipping underserved Chicagoland teens and young adults with AI fluency, work-readiness, and a
real path to a job or a venture of their own.

"Chi-Spark AI" is a working name pending trademark & availability check.

## Stack

- [Vite](https://vite.dev) + React + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs a static site to `dist/`, deployable to any static host (GitHub Pages, Netlify, Vercel,
etc.).

## Content source

Copy and structure are drawn from the Chi-Spark AI brand identity guide and founding business
plan (mission, four pillars, two program tracks, values, and voice guidelines).

## Notes for launch

- Swap the placeholder contact address (`hello@chisparkai.org`) in `src/components/Contact.tsx`
  and `src/components/GetInvolved.tsx` for a real inbox before going live.
- The site copy avoids financial figures and funder-specific details — those live in the
  internal business plan, not the public site.
